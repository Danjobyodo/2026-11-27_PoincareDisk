# 双曲平面 $\mathbb{H}^2$ 対話実験室 (PWA)

ポアンカレ円板モデル $\mathbb{H}^2 = \{z \in \mathbb{C} : |z| < 1\}$（定ガウス曲率 $K = -1$）上の双曲幾何学を視覚的・数値的に実演・検証するオフライン対応 Web アプリ (PWA) です。Mac の Safari・iPhone の Safari の両方で快適に動作するよう設計しています。

## 採用している定義・記号

- **空間**: $\mathbb{H}^2 = \{z \in \mathbb{C} : |z| < 1\}$
- **双曲距離**:
  $$d(z, w) = \log\left(\frac{1 + \left|\frac{z-w}{1-\bar{z}w}\right|}{1 - \left|\frac{z-w}{1-\bar{z}w}\right|}\right)$$
- **向きを保つ等長変換群**:
  $$\operatorname{Isom}_+(\mathbb{H}^2) = \{\varphi_{\theta, \alpha} : \theta \in [0, 2\pi),\; \alpha \in \mathbb{H}^2\}, \qquad \varphi_{\theta, \alpha}(z) = e^{i\theta}\frac{z - \alpha}{1 - \bar{\alpha}z}$$
- **双曲面積**:
  $$\operatorname{Area}(B) = \iint_B \frac{4}{(1 - |z|^2)^2}\,dx\,dy$$

## 主な機能

1. **三角形・多角形と面積 (ガウス–ボネの定理)**
   - 円板内タップ・ドラッグ・高精度座標指定（直交 $(x,y)$・極座標 $(r,\theta)$・境界距離 $(1-\delta,\theta)$・双曲極座標 $(\rho,\theta)$）で自由に頂点を配置。
   - 独立した数値積分 $\iint_T \frac{4}{(1-|z|^2)^2}\,dx\,dy$ とガウス–ボネ公式 $\pi - (\alpha+\beta+\gamma)$（一般の $n$ 角形では $(n-2)\pi - \sum\alpha_k$）および L'Huilier 公式をリアルタイム比較（直接 2D ガウス求積での再照合も可能）。
   - 双曲第1・第2余弦定理、双曲正弦定理、内心・外心・重心（双曲平面内に外接円が存在しない場合の表示を含む）の確認。
   - プリセット: 標準三角形・理想三角形近傍 ($1-r=10^{-4}$)・極限境界 ($1-r=10^{-10}$)・微小三角形・直角正五角形（各内角 $\pi/2$、面積 $\pi/2$）。

2. **点・測地線・双曲円**
   - 双曲距離 $d(z, w)$、擬双曲距離 $\rho(z, w)$、測地線、双曲中点 $M$、垂直二等分線の表示。
   - 双曲円 $B_H(A, R)$ の厳密周長 $2\pi\sinh R$・厳密面積 $4\pi\sinh^2(R/2)$ と数値積分の照合、および双曲中心とユークリッド中心のズレの可視化。
   - 垂線長 $h$ とロバチェフスキーの平行角 $\Pi(h) = 2\arctan(e^{-h})$ の表示。

3. **等長変換 $\operatorname{Isom}_+(\mathbb{H}^2)$**
   - $\alpha$ の直接ドラッグと $\theta$ スライダー、1パラメータ部分群 $\varphi^t$ の滑らかなアニメーション。
   - $\operatorname{SU}(1,1)$ トレースによる楕円型・放物型・双曲型の自動分類、不動点、不変曲線（同心双曲円・ホロサイクル・並進軸と等距離曲線）、反復軌道 $\varphi^n(A)$ の描画。
   - 変換前後の距離・数値面積の保存をリアルタイム検証。

4. **定理検証ラボ**
   - 15 個の既知の定理・境界精度・極限ガードをブラウザ上で一括実行し、各テストケースをワンタップで盤面に再現可能。

## 境界近傍の高精度計算と精度ガード

- すべての幾何計算を **106bit 倍々精度 (Double-Double, 約31桁)** (`js/dd.js`) で実装しています。
- 距離は桁落ちしない恒等式 $d(z,w) = 2\operatorname{arsinh}\!\left(\frac{|z-w|}{\sqrt{(1-|z|^2)(1-|w|^2)}}\right)$ で計算しています。
- 面積の数値積分はグリーンの定理 $\oint_{\partial B}\frac{2(x\,dy - y\,dx)}{1-|z|^2}$ を測地線弧長パラメータで適応 16 点ガウス・ルジャンドル求積（被積分関数が境界近傍でも常に $|f| < 1$ で有界）することにより、$1 - |z| = 10^{-12}$ 付近でも 15 桁以上の精度を維持します。
- 推定有効数字が 7 桁未満になる極端領域 ($1 - |z|^2 < 10^{-23}$) では、誤った値を表示せず非表示ガードが働きます。

## 起動方法・PWA (オフライン利用)

外部 CDN に一切依存しない完全ローカル構成です。

### Mac Safari で開く（ローカルサーバー推奨・PWA オフラインキャッシュ有効）
ターミナルでこのフォルダに移動して以下を実行し、Safari で `http://localhost:8000` を開きます。
```bash
python3 -m http.server 8000
```
一度開くと Service Worker (`sw.js`) が全ファイルをキャッシュするため、以降はオフラインでも動作します。  
（※ `index.html` を直接ダブルクリックして `file://` で開いても全機能動作しますが、Service Worker によるオフライン PWA 化には `http://localhost` または `https://` が必要です。）

### iPhone Safari でホーム画面に追加 (オフライン PWA)
- GitHub Pages などの HTTPS サーバーにこのフォルダをそのまま配置し、iPhone の Safari で開いて **共有ボタン →「ホーム画面に追加」** をタップしてください。一度開けば機内モード（オフライン）でも動作します。
