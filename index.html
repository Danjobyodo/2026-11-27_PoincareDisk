定義・記号と高精度計算の仕組み

ポアンカレ円板モデル (定ガウス曲率 K = −1)
ℍ² = { z ∈ ℂ : |z| < 1 },   ds = 2|dz| / (1 − |z|²)
双曲距離
d(z, w) = log( (1 + |(z − w)/(1 − z̄w)|) / (1 − |(z − w)/(1 − z̄w)|) )
※ 数値計算では桁落ちのない恒等式 d(z,w) = 2·arsinh(|z−w| / √((1−|z|²)(1−|w|²))) を106bit倍々精度 (Double-Double) で評価しています。
向きを保つ等長変換群
Isom₊(ℍ²) = { φθ,α : θ ∈ [0, 2π), α ∈ ℍ² }
φθ,α(z) = eiθ · (z − α) / (1 − ᾱz)
双曲面積とガウス–ボネの定理
Area(B) = ∬B 4 / (1 − |z|²)² dx dy
測地線三角形 T の内角を α, β, γ とすると Area(T) = π − (α + β + γ)
境界 |z| → 1 近傍での精度保証と非表示ガード
通常のIEEE-754倍精度 (約16桁) では 1 − |z| < 10−8 付近で桁落ちや発散が生じます。本アプリでは全幾何演算を 106bit 倍々精度 (約31桁) で実装し、さらに面積数値積分ではグリーンの定理に基づく測地線弧長パラメータの適応ガウス・ルジャンドル求積（被積分関数が境界近傍でも常に有界 |f| < 1）を用いることで、1 − |z| = 10−12 領域でも15桁以上の精度を実現しています。
信頼できる有効数字が7桁未満になる極端な領域 (1 − |z|² < 10−23) では、誤った数値を出さず非表示とします。
